
\section{Setup and Training Motion}
Moving MNIST uses a fixed 8,000/1,000/1,000 train/validation/test video split, with twenty $64\times64$ grayscale frames per video. Five inputs forecast five frames; at $3\times$ and start 1, only two targets exist. All learned models use Adam at $10^{-3}$, batch size 32, 30 epochs, final weights and seeds 0/1 on an NVIDIA A100-SXM4-40GB. Loss weights videos equally after averaging their valid targets. Tests use all 1,000 videos at start 1; entries are mean (seed 0, seed 1). $E^{(5)}$ and $E^{(2)}$ average five and two horizons respectively.
\[
C_T=\operatorname{MSE}\!\left(f(TX),T(f(X))\right),\qquad
E_T=\operatorname{MSE}\!\left(f(TX),T(Y)\right).

\section{The Final Model}
The final model is symmetrised D, the prescribed default. D gives the lowest mean $3\times$ error in Table 5. No optional D+B run or additional training is used. All eight transformed branches run the complete forecaster before inverse transformation and averaging; they share one set of weights.
The group is $G=\{R^a,MR^a:a=0,1,2,3\}$; $MR^a$ rotates first and then mirrors.
\[
\bar f(X)=\frac18\sum_{g\in G}g^{-1}f(gX).
\]
For $h\in G$, set $q=gh$. Right multiplication permutes the group and $g^{-1}=h q^{-1}$, so
\[
\bar f(hX)=\frac18\sum_{q\in G}h q^{-1}f(qX)=h\bar f(X).
\]
A mirror/rotation is a linear pixel permutation, so it commutes with averaging. Thus $C_M=C_R=0$ in exact arithmetic for any base forecaster. The measured floating-point gaps are retained in Table 6.
